Developer tools

I've developed all kinds of (mostly artist-facing) tools and pipeline improvements across Houdini, Unreal, Unity, Maya, Blender, and in-house engines. My work ranges from automating repetitive tasks to building tools for debugging, asset validation, content generation, and day-to-day workflow support.

I’m interested in making tools useful and understandable, and improving pipelines as a whole so artists can focus on doing their best work.

Some small examples of tools:

- Debugging tools: Helpers for investigating issues in Pax Dei, alongside collision-debugging tools for Unreal.
- Asset validation and processing: An Unreal asset validator, an HLOD generator for Pax Dei
- Various batch-processing utilities to optimize performance and catch problematic assets.
- Version-control helpers: Perforce tools for Houdini and Maya.
- Script distribution: A tool for distributing scripts to Maya users.
- Artist launcher: A launcher to bring common artist tasks and tools into one place.
